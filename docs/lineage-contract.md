# Project Savitar — governance contract

This document describes the W3C PROV-O mapping used by the governance and lineage system.

## Mapping

- Entity = a persisted output or data item; mapped to prov:Entity
- Activity = transformation, scoring, merge, conflict resolution, or query execution; mapped to prov:Activity
- Agent = actor, identity, or role that performed the activity; mapped to prov:Agent

### Minimum provenance contract

Each output must include:
- output_type
- output_id
- inputs[]: versioned source identifiers and content hashes, never raw values
- transformations[]
- model_versions[]
- timestamp
- actor

## Example

A risk score generated by an analyst is represented as:
- prov:Entity = risk score output
- prov:Activity = score computation
- prov:Agent = analyst
- prov:used = source snapshots
- prov:wasGeneratedBy = score generation

The `lineage_record` object is the canonical record used to enforce fail-closed emission.
